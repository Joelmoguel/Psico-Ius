## 📁 Archivos

- **index.html** - Página principal (38.8 KB)
- **gracias.html** - Página de confirmación post-formulario (13 KB)
- **DEPLOYMENT_GUIDE.md** - Guía completa de implementación

## 🚀 Inicio Rápido

### 1. Configurar Formspree

En `index.html`, línea 403, reemplaza `TU_ENDPOINT`:

```html
<form action="https://formspree.io/f/TU_ENDPOINT" method="POST">
```

### 2. Publicar

**GitHub Pages:**
1. Settings > Pages
2. Selecciona la rama y carpeta root
3. ¡Listo! Tu sitio estará en: `https://joelmoguel.github.io/Psico-Ius/`

**Netlify:**
1. Arrastra los archivos a [netlify.com/drop](https://app.netlify.com/drop)
2. ¡Listo!

### 3. Compartir

Comparte el enlace completo en redes sociales. Facebook/Instagram generarán automáticamente una preview.
